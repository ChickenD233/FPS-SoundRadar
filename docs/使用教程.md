# SoundRadar 使用教程(3 步上手)

## 第 1 步:装 Voicemeeter Potato(一次性,约 5 分钟)

1. 打开 https://vb-audio.com/Voicemeeter/potato.htm
2. 点下载,安装,**重启电脑**(必须重启)。
3. 重启后打开 Potato，点右上角 **Menu**，勾上 **Run on Windows startup**（以后开机自动运行）。

## 第 2 步:让游戏声音走 7.1(一次性，约 2 分钟)

1. 右键任务栏右下角的小喇叭 → **声音设置** → **更多声音设置**（或"声音控制面板")。
2. 在"播放"列表里找到 **Voicemeeter Input**，右键 → **设为默认设备**。
3. 再右键它 → **配置扬声器** → 选 **7.1 环绕** → 下一步到底。
4. 在 Potato 窗口中间找到 **Voicemeeter Input** 那一竖条，把它下面的 **B1** 按钮点亮（变绿）,**A1** 点灭（变灰）。
5. 游戏里如果自己能选音频输出设备，也选 **Voicemeeter Input**。

## 第 3 步:开 SoundRadar

1. 双击 `SoundRadar.exe`，主窗口弹出。
2. **输出设备**选你的真实耳机(带"(虚拟)"字样的不要选)。
3. **下混模式**选一个（只有两种）：
   - **全景声 Stereo**：默认。7.1 转双声道，左右耳分开，方向感保留。
   - **单声道 Mono**：7.1 八个声道合成一路，两耳听同一份，不区分方向。
4. 点 **应用**。状态栏显示"运行中"就好了。切模式不需要重启，立即生效。

进游戏，看到屏幕中间的空心圆环上有箭头指向声源 = 成功。

单声道模式用"权重"滑块（FL/FR/C/LFE/BL/BR/SL/SR）调整每个声道所占的比例。

## 常用调整(主窗口里直接拖)

每个滑块都是**左低右高**：低端叫"低"，用荧光蓝显示；高端叫"高"，用橙色显示。滑块轨道两端和提示文字里的"低/高"用的是同一套颜色，看到颜色就知道该往哪边拖。

每个滑块下面还有一行小字写着"往哪边拖会怎样"。速查表：

| 想要什么 | 调哪里 | 方向 |
|---|---|---|
| 声纹太暗/太小看不清 | 灵敏度 | 调**高**（提亮+提早变红） |
| 声纹太亮、全是红色 | 灵敏度 | 调**低** |
| 轻脚步完全没声纹 | 高级页「检测灵敏度」 | 调**低**（2 最灵敏，默认 4） |
| 还是不够灵敏 | 检测门限 | 也调**低** |
| 噪声里出现假箭头 | 检测门限 | 调**高** |
| 雷达挡视野 | 雷达大小 / 位置X / 位置Y | 调**低** / 负=左 / 调**高**下移 |
| 箭头收尾太生硬或太拖 | 渐隐时间 / 指针残留 | 渐隐时间调**高**收尾更柔和；指针残留调**低**更干净 |
| 箭头追不上快速转身的声源 | 指针残留 | 调**低** |
| 箭头闪烁跳变 | 指针残留 | 调**高** |
| 绿黄红变色太灵敏 | 阈值 绿→黄 | 调**低** |
| 只有很近才想变红 | 阈值 黄→红 | 调**高** |
| 想更灵敏地看到箭头 | 检测门限 | 调**低**（可能多出噪声箭头） |
| 只想看到明确的声音 | 检测门限 | 调**高** |
| 脚步/枪声图标太乱 | 分类能量门限 | 调**高** |
| 想后方声音更响 | 权重区 BL、BR | 调**高**（单声道模式） |
| 自己的枪声/脚步挡视线 | 开枪削弱 / 走路削弱 | 调**高** |
| 不想看雷达只听声音 | 显示声纹 | 关（对音频零影响） |
| 听不出左右，只要声音清楚 | 下混模式 | 单声道 |

## 想听到很轻的脚步声（例如只开 20% 游戏音量）

引擎的判定阈值现在比环境噪声底高约 **8–12 dB** 就能触发（旧版要 15–18 dB）。如果还是不够：

1. 高级页 → **实验：指针跟随** → **检测灵敏度** 调到 **2–3**。这是判定阈值的余量，数字越小越灵敏。
2. **检测门限** 也往下调（它决定多小的声音才会画出箭头）。
3. 如果游戏音量只有 20%，数字信号本身就很低。最有效的做法是在虚拟声卡那一侧提增益：用 Voicemeeter 时把该 Input 的 **B1 推子**推高；用 VB-CABLE 时把游戏/系统音量提高。
4. 环境底噪越大（风扇、机箱），可检测的最轻脚步就越受限——因为此时脚步声和底噪的差距被压小了。这是物理限制，不是阈值能解决的。

## 实验功能：指针跟随转向（抵消声音延迟）

原理：游戏里的声音固定在**世界方向**上，但你的视角在转。声音有延迟时，声纹画的是"你转身之前的方位"。开启这个功能后，声纹会按你转过的角度反向旋转，指向"相对当前视角"的方位。

设置步骤：

1. 高级页 → **实验：指针跟随** → 打开"指针跟随转向"。
2. **游戏**：选你正在玩的（CS2 / 无畏契约 / Apex / 守望先锋 2）。其他游戏选"自己填"。
3. **鼠标 DPI**：填鼠标驱动里设置的 DPI（不是游戏内灵敏度）。
4. **游戏内灵敏度**：填游戏设置里的那个数字。下面立刻算出"每计数转多少度"和"转一整圈约多少厘米"。
5. 核对：在游戏里正好转一整圈 360°，量鼠标在垫子上走了多少厘米。和算出的厘米数差多少，就用"灵敏度校正"补多少（例如实际是 30 cm 而算出 26 cm，就把校正调到约 115%）。
6. 如果声纹转向和鼠标方向相反，打开"反向"。

游戏里的 yaw 系数（每计数转多少度，灵敏度 1.0 时）：CS2 / Apex `0.022`，无畏契约 `0.07`，守望先锋 2 / 使命召唤 `0.0066`。所以无畏契约的灵敏度 ≈ CS2 灵敏度 × 3.18。

注意：不同网站给出的 cm/360 会差约 2 倍，所以**以自己量出来的厘米数为准**，算出来的数字只是起点。

限制：声纹方向来自 8 声道布局，所以旋转是 30°/60° 一档一档跳的，不是平滑连续。若游戏不用原始鼠标输入、或开了鼠标加速，公式会有偏差，用"灵敏度校正"手调到看起来对为止。

## 常见问题

- **雷达不动**:Potato 没开，或那条 Input 的 B1 没点亮。
- **轻脚步完全看不到声纹**:高级页的"检测门限"往低拖（不是"灵敏度"，那个只改亮度）。
- **没声音**：输出设备选错了，重新选你的耳机，点应用。
- **想彻底退出**：托盘绿色雷达图标 → 右键 → 退出。点窗口的 X 只是最小化。
- **出问题看日志**:`Win+R` 输入 `%APPDATA%\SoundRadar` 回车，打开 log.txt。
