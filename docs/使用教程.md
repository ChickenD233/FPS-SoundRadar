# SoundRadar 使用教程(3 步上手)

## 第 1 步:装 Voicemeeter Potato(一次性,约 5 分钟)

1. 打开 https://vb-audio.com/Voicemeeter/potato.htm
2. 点下载,安装,**重启电脑**(必须重启)。
3. 重启后打开 Potato，点右上角 **Menu**，勾上 **Run on Windows startup**（以后开机自动运行）。

## 第 2 步:让游戏声音走 7.1(一次性，约 2 分钟)

1. 右键任务栏右下角的小喇叭 → **声音设置** → **更多声音设置**（或"声音控制面板")。
2. 在"播放"列表里找到 **Voicemeeter Input**，右键 → **设为默认设备**。
3. 再右键它 → **配置扬声器** → 选 **7.1 环绕** → 下一步到底。
4. 在 Potato 窗口中间找到 **Voicemeeter Input** 那一竖条，把它下面的 **B1** 按钮点亮（变绿）,**A1** 点灭（变灰）。
5. 游戏里如果自己能选音频输出设备，也选 **Voicemeeter Input**。

## 第 3 步:开 SoundRadar

1. 双击 `SoundRadar.exe`，主窗口弹出。
2. **输出设备**选你的真实耳机(带"(虚拟)"字样的不要选)。
3. 模式保持 **右耳单声道**。
4. 点 **应用**。状态栏显示"运行中"就好了。

进游戏，看到屏幕中间的空心圆环上有箭头指向声源 = 成功。所有声音都会进你的右耳。

## 常用调整(主窗口里直接拖)

| 想要什么 | 调哪里 |
|---|---|
| 箭头太亮/太暗 | 特效强度滑块 |
| 雷达挡视野 | 雷达大小调小，或位置 X/Y 挪到边上 |
| 声音消失后箭头停留太久/太短 | 渐隐时间(300–500 毫秒) |
| 想让后方声音更响 | 权重区的 BL、BR 拉高 |
| 绿黄红变色太灵敏/太迟钝 | 阈值两个滑块 |
| 不想看雷达只听声音 | 关掉"显示声纹"(对音频零影响) |

## 常见问题

- **雷达不动**:Potato 没开，或那条 Input 的 B1 没点亮。
- **没声音**：输出设备选错了，重新选你的耳机，点应用。
- **想彻底退出**：托盘绿色雷达图标 → 右键 → 退出。点窗口的 X 只是最小化。
- **出问题看日志**:`Win+R` 输入 `%APPDATA%\SoundRadar` 回车，打开 log.txt。
