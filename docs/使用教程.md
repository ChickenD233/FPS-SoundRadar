# SoundRadar 使用教程(3 步上手)

## 第 1 步:装 Voicemeeter Potato(一次性,约 5 分钟)

1. 打开 https://vb-audio.com/Voicemeeter/potato.htm
2. 点下载,安装,**重启电脑**(必须重启)。
3. 重启后打开 Potato，点右上角 **Menu**，勾上 **Run on Windows startup**（以后开机自动运行）。

## 第 2 步:让游戏声音走 7.1(一次性，约 2 分钟)

1. 右键任务栏右下角的小喇叭 → **声音设置** → **更多声音设置**（或"声音控制面板")。
2. 在"播放"列表里找到 **Voicemeeter Input**，右键 → **设为默认设备**。
3. 再右键它 → **配置扬声器** → 选 **7.1 环绕** → 下一步到底。
4. 在 Potato 窗口中间找到 **Voicemeeter Input** 那一竖条，把它下面的 **B1** 按钮点亮（变绿）,**A1** 点灭（变灰）。
5. 游戏里如果自己能选音频输出设备，也选 **Voicemeeter Input**。

## 第 3 步:开 SoundRadar

1. 双击 `SoundRadar.exe`，主窗口弹出。
2. **输出设备**选你的真实耳机(带"(虚拟)"字样的不要选)。
3. **下混模式**选一个：
   - **7.1 立体声（全景声）**：默认。左右耳分开，7.1 空间感保留，方向最准。
   - **右耳单声道 Right-Mono**：所有声道混进右耳，左耳静音。
   - **左耳单声道 Left-Mono**：所有声道混进左耳，右耳静音。
4. 点 **应用**。状态栏显示"运行中"就好了。切模式不需要重启，立即生效。

进游戏，看到屏幕中间的空心圆环上有箭头指向声源 = 成功。

两个单声道模式用同一组"权重"滑块（FL/FR/C/LFE/BL/BR/SL/SR）；想让后方声音更响就把 BL、BR 拉高。单声道模式下左前右前的方向箭头照常工作，只是不再做左右平移。

## 常用调整(主窗口里直接拖)

每个滑块都是**左低右高**：低端叫"低"，用荧光蓝显示；高端叫"高"，用橙色显示。滑块轨道两端和提示文字里的"低/高"用的是同一套颜色，看到颜色就知道该往哪边拖。

每个滑块下面还有一行小字写着"往哪边拖会怎样"。速查表：

| 想要什么 | 调哪里 | 方向 |
|---|---|---|
| 声纹太暗/太小看不清 | 灵敏度 | 调**高**（提亮+提早变红） |
| 声纹太亮、全是红色 | 灵敏度 | 调**低** |
| 轻脚步完全没声纹 | 检测门限 | 调**低**（决定能否检测到） |
| 噪声里出现假箭头 | 检测门限 | 调**高** |
| 雷达挡视野 | 雷达大小 / 位置X / 位置Y | 调**低** / 负=左 / 调**高**下移 |
| 箭头消失太慢或太快 | 渐隐时间 | 调**低**更快，调**高**更久 |
| 箭头追不上快速转身的声源 | 指针残留 | 调**低** |
| 箭头闪烁跳变 | 指针残留 | 调**高** |
| 绿黄红变色太灵敏 | 阈值 绿→黄 | 调**低** |
| 只有很近才想变红 | 阈值 黄→红 | 调**高** |
| 想更灵敏地看到箭头 | 检测门限 | 调**低**（可能多出噪声箭头） |
| 只想看到明确的声音 | 检测门限 | 调**高** |
| 脚步/枪声图标太乱 | 分类能量门限 | 调**高** |
| 想后方声音更响 | 权重区 BL、BR | 调**高**（单声道模式） |
| 自己的枪声/脚步挡视线 | 开枪削弱 / 走路削弱 | 调**高** |
| 不想看雷达只听声音 | 显示声纹 | 关（对音频零影响） |
| 只想用一只耳朵听 | 下混模式 | 右耳单声道 / 左耳单声道 |

## 常见问题

- **雷达不动**:Potato 没开，或那条 Input 的 B1 没点亮。
- **轻脚步完全看不到声纹**:高级页的"检测门限"往低拖（不是"灵敏度"，那个只改亮度）。
- **没声音**：输出设备选错了，重新选你的耳机，点应用。
- **想彻底退出**：托盘绿色雷达图标 → 右键 → 退出。点窗口的 X 只是最小化。
- **出问题看日志**:`Win+R` 输入 `%APPDATA%\SoundRadar` 回车，打开 log.txt。
